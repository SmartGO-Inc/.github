# SmartGO — Plataforma de Gestion POS

**Perteneciente a Vanda**

Plataforma de punto de venta y gestion operativa que centraliza inventario, ventas y administracion en un ecosistema unificado.

---

## Sobre la organizacion

SmartGO nace dentro de **Vanda** para construir soluciones tecnologicas que modernicen la operativa de retail y gestion de inventario. Todos los proyectos estan orientados a simplificar, auditar y acelerar los flujos de venta y abastecimiento, reemplazando procesos manuales por herramientas digitales robustas y trazables.
