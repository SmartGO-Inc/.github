# .github

Repositorio especial de GitHub para la organizacion **Vanda SaaS — SmartGO**.

Este repositorio define los archivos por defecto que se aplican a todos los proyectos de la organizacion. Cada repositorio hijo puede sobrescribir cualquiera de estos archivos si necesita reglas especificas.

## Contenido

| Archivo                      | Proposito                                                    |
|------------------------------|--------------------------------------------------------------|
| `profile/README.md`          | Perfil de la organizacion en GitHub                          |
| `CONTRIBUTING.md`            | Guia general de contribucion (cada repo puede refinarla)     |
| `CODE_OF_CONDUCT.md`         | Codigo de conducta para todos los proyectos                  |
| `SECURITY.md`                | Politica de seguridad y reporte de vulnerabilidades          |
| `LICENSE`                    | Licencia MIT                                                 |
| `.github/ISSUE_TEMPLATE/`    | Templates para issues (bugs, features)                       |
| `.github/pull_request_template.md` | Template para pull requests                            |

> Los archivos de este repositorio se heredan automaticamente a cada repositorio de la organizacion que no tenga los suyos propios.
